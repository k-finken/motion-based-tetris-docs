Motion-Based Tetris is a Python desktop application that uses your webcam to detect hand gestures in real time and translate them into Tetris controls on [tetris.com](https://tetris.com/play-tetris). Powered by MediaPipe and CVZone, the app reads which fingers you're holding up and fires the corresponding keyboard inputs — so you can move, rotate, and drop pieces without ever touching your keyboard.

## Quick Start

<Steps>
  <Step title="Clone the repo and create a virtual environment">
    Clone the repository to your local machine and open a terminal inside the project folder. Create a new virtual environment with `python -m venv venv`, then activate it by running `venv\scripts\activate` on Windows.
  </Step>
  <Step title="Install dependencies">
    With the virtual environment active, install all required packages by running:

    ```bash
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Open tetris.com and focus the page">
    Navigate to [tetris.com/play-tetris](https://tetris.com/play-tetris) in your browser and click anywhere on the page to make sure it has keyboard focus. The app sends keystrokes directly to the focused window, so this step is essential.
  </Step>
  <Step title="Run the app and start gesturing">
    Back in your terminal, launch the application:

    ```bash
    python main.py
    ```

    The game window will open. Make sure **both hands are visible** in the webcam feed displayed inside the window — gestures are only detected when both hands are in frame. Start making gestures to control the Tetris pieces. Press `Escape` at any time to return to the menu.
  </Step>
</Steps>
